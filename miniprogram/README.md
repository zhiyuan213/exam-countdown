# 考试倒计时 · 小程序前端

**注意：这是重写版本，不是原始前端。**

原因：原前端源码只存在于旧电脑的微信开发者工具项目目录（已随格式化丢失），微信后台也不提供源码下载，
后端 `app.jar` 里只有 Java 字节码 —— 所以前端没有"恢复"的可能，只能按**后端接口契约 + 已知页面路径**
（`pages/index/index?examId=`）重新实现。交互与视觉可能与原版有差异，可按需要继续调整。

## 导入运行

1. 微信开发者工具 → 导入项目 → 选择本目录（`miniprogram/`）
2. AppID 已预填 `wx23a7083f915b62a1`
3. 首次编译前，确认这两个值正确：

| 位置 | 变量 | 说明 |
|---|---|---|
| `utils/api.js` | `ENV_ID` | 云托管环境 ID，当前为 `prod-exam-d9g96663daa04cb57` |
| `utils/api.js` | `SERVICE` | 云托管服务名，当前 `exam-backend` |
| `utils/api.js` | `APP_KEY` | 矩阵标识，`main` = 返回全部考试；`kaoyan` / `jiaozhi` 按赛道过滤 |

> 云托管服务必须处于**运行状态**（当前 `exam-backend-023` 显示"版本停止"，需先启动），否则 callContainer 会失败。

## 已实现的功能

- **自动登录**：`app.js` 启动即调 `/api/auth/login`，openid 由云托管平台注入请求头，前端不需要传 code
- **节点列表**：`/api/exams`，按 `groupCode` 分组（考研 / 教资…），组内按日期排序
- **倒计时**：前端按 `examDate` 计算剩余天数，`今天 / 明天 / N 天后 / 已结束`；≤7 天标红
- **订阅提醒**：先 `wx.requestSubscribeMessage`（用该节点的 `templateId`），授权通过再 `POST /api/subscribe` 登记额度
- **推送深链**：订阅消息点击后跳 `pages/index/index?examId=xxx`，对应节点高亮显示
- **下拉刷新**
